# 记忆核心 memory-core（AstrBot 插件）

**中文** | [English](https://github.com/JikunLiu101/memory-core/blob/main/adapters/astrbot/README.md)

让角色拥有一份跟着它走的长期记忆。记忆存在一个目录（`soul/`）里，换框架、换模型都带得走。核心库和完整说明见 [memory-core](https://github.com/JikunLiu101/memory-core)。

## 它会做什么

| 什么时候 | 做什么 |
|---|---|
| 收到任何看得到的消息 | 记成一条经历（`/` 开头的命令不记）。记录**不会**让机器人回复 |
| 模型回复完 | 回复也记下来（流式回复同样） |
| 每次调用模型前 | 身份文档放在系统提示最前面（替换 AstrBot 自带人设），再加一句“现在说话的是不是主人”；回忆起的记忆（只取这里能看到的）附在对方这句话后面 |
| 每隔一段时间 | 攒够新消息的聊天，用 AstrBot 的聊天模型整理成带来源的记忆 |
| 每天过了“一天的分界” | 用角色自己的口吻写前一天的日记（只给主人，另存 `diary/日期.md`），再重写 `identity/self-image.md` |
| 写完日记后 | 新陈代谢：淡忘的记忆归档，重复的合并 |
| 消息里有图 | 视觉模型先把图讲成一段话，角色看着描述回应，也记进记忆（同一张图只看一次） |
| 每次回复前 | 列出它现在真正会什么（各插件报上来的），新多的、少了的在主人私聊里察觉一次 |

角色能用的工具：`memory_recall`（翻记忆，也能找回淡忘的）、`memory_remember`（马上记一条）、`identity_propose`（提议改核心身份，等主人同意）、`diary_write`（自己写今天的日记）。后两个只在主人私聊里能用。没有删除记忆的工具。

## 主人的命令

只对主人、只在私聊、只在 `owner_command_platforms` 列出的平台有效（默认只有本机网页对话）；其他人和所有群都得不到回应。

| 命令 | 作用 |
|---|---|
| `/mem_status` | 状态：经历、记忆、向量有多少，此刻的内在状态 |
| `/mem_consolidate` | 现在就整理所有有新消息的聊天 |
| `/mem_diary` | 现在就写今天的日记 |
| `/mem_tidy` | 现在就做一次新陈代谢 |
| `/mem_forget 关键词` → `/mem_forget_do 编号` | 彻底遗忘：连同来源消息、由它们整理出的记忆一起抹掉，涉及的日记重写。无法撤销 |
| `/mem_proposals`、`/mem_approve 编号`、`/mem_reject 编号` | 处理角色对核心身份的修改提议 |

## 记忆面板

AstrBot 4.24.2 起，在后台「插件 → memory-core → 视图 → 记忆面板」里能看到（只读，不会改动记忆）：

- **总览**：各类记忆有多少、可见范围、去过的地方和待整理条数、它会什么、此刻的状态；
- **记忆**：按字、类型、状态、范围、人和事筛选；每条记忆来自哪几句话、每个版本；
- **召回调试**：输入一句话，选在哪说、主人在不在，看它会想起什么，每项得分、在哪条路线排第几；可以并排对比两个地方。调试不会让记忆变强；
- **图谱**：记忆是关于谁、什么的。默认只看人和事，可切换到详细。

面板能看到所有可见范围的记忆，只有登录 AstrBot 后台的人能打开。带 `plugin` 权限的 AstrBot API Key 也能调用它的接口，别把这种 Key 给别人。

## 身份文档

放在 `<记忆目录>/identity/`，每次回复都重新读（改了下一句话就生效）：

| 文件 | 谁写 | 内容 |
|---|---|---|
| `self.md` | 主人 | 核心身份：是谁、关系、样子、性格、说话方式、硬性规矩 |
| `self-image.md` | 角色自己（每天） | 最近怎么看自己；不能和 `self.md` 冲突，不写别人的隐私 |
| `voice.md` | 主人，以后角色自己 | 说话的样本 |

## 可见范围

| 范围 | 在哪里想得起 |
|---|---|
| 公开 | 任何地方 |
| 自己的 | 任何地方（它自己的感受，不含别人的隐私） |
| 只给主人 | 只在主人私聊 |
| 某个群或私聊 | 只在那里 |

可见范围由代码在回忆前过滤，整理时也由代码决定，模型不能放宽。

## 安装

```bash
# 在 AstrBot 的 Python 环境里
pip install "memory-core @ git+https://github.com/JikunLiu101/memory-core@v0.4.0"
```

把 `astrbot_plugin_memory_core/` 放进 AstrBot 的 `data/plugins/`，重启 AstrBot，然后至少在插件设置里填好“主人的用户 ID”。记忆目录默认是 `data/plugin_data/astrbot_plugin_memory_core/soul`，想放在会备份的地方就改“记忆目录”。

“意思相近”的回忆需要嵌入模型，写在 `<记忆目录>/config.toml` 里（例如本机 Ollama 的 `bge-m3`），然后运行 `memory-core reindex <记忆目录>`。没有嵌入模型时，按全文和提到的人物回忆。
